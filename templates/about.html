How I Work

The principles that guide how I build software.

🎯

Problem First, Code Second

I don't write a single line until I fully understand the problem. I ask questions, dig into the "why," and only then design the solution.

🧪

Tested Code is Trusted Code

If it's not tested, I don't consider it done. Tests aren't optional — they're the proof that what I built actually works.

📦

Ship Early, Iterate Fast

Perfection is the enemy of progress. I ship a working version fast, then improve based on real feedback — not assumptions.

📖

Code is Communication

I write code for humans first, machines second. Clear naming, thoughtful comments, and clean architecture matter.
